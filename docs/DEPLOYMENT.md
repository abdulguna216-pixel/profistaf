# Размещение на GitHub и Vercel

Репозиторий: https://github.com/abdulguna216-pixel/profistaf

Проект Vercel: `profistaf`, аккаунт `abdulguna216-4917`. Ветка публикации — `main`. Корневая директория приложения — корень репозитория; дополнительный `site/` в настройках Vercel не нужен.

Сборка: Node.js 24, pnpm 11.25.0, framework Vite, команда `pnpm run build`, результат `dist/`. Vercel использует версию pnpm из packageManager через Corepack (`ENABLE_EXPERIMENTAL_COREPACK=1`). Настройки framework/build/output закреплены в vercel.json.

Зависимости, dist, .vercel, локальные .env и служебные файлы исключены из Git. QA-скриншоты и проектная документация остаются в GitHub, но не загружаются через Vercel CLI.

Форма пока работает в демонстрационном режиме. Для реальной доставки нужны серверный обработчик, настройки Telegram и согласованный текст политики обработки данных. Токен Telegram необходимо хранить только в серверных переменных Vercel; переменные VITE_* доступны посетителю.

Для последующих обновлений вносите изменения в исходники и отправляйте их в main. При подключённой Git-интеграции Vercel выполняет сборку и публикацию автоматически.
